## 🚀 Projetos

### 💳 SmartPOS — Python, SQL e IA

Sistema de vendas desenvolvido em Python que simula operações de débito, crédito à vista e parcelado.

A aplicação utiliza SQLite para armazenamento das vendas e consultas SQL para geração de relatórios e indicadores, como faturamento, ticket médio e forma de pagamento mais utilizada.

O projeto também possui o SmartPOS Insights, funcionalidade que integra a Gemini API para gerar análises das vendas em linguagem natural a partir dos dados processados pelo sistema.

Tecnologias: Python • SQL • SQLite • Gemini API

[Ver projeto](https://github.com/Walace-da-Costa-Santos/smartpos-python-sql-ia)
